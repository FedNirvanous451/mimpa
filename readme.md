## Практика 1. Парсинг данных
**Цель:** Сбор трех различных наборов данных через открытые API.

В рамках работы были получены данные из трех разных источников:
*   **Временной ряд:** Почасовая температура в г. Мурманск за 2024 год (API `Open-Meteo`). 
*   **Многомерные данные:** Социально-экономические показатели стран за 2018–2022 гг. (API `World Bank`). 
*   **Текстовый корпус:** Новостные статьи за 2004 год (API `The Guardian`).

**Что было сделано:**
*   Настроены HTTP-запросы с использованием `requests`.
*   Обработаны лимиты (rate limits) и ошибки соединения.
*   Данные очищены от дубликатов и пропусков.
*   Данные сохранены в форматы CSV и JSON с фиксацией даты загрузки.

### ✅ Результаты
В результате работы сформированы три очищенных датасета. Настроена устойчивая обработка ошибок API. Все данные успешно сохранены в структурированном виде и готовы к дальнейшему анализу и обучению моделей.

## Практика 2. Рекомендательные системы
**Цель:** Построение модели коллаборативной фильтрации на основе матричного разложения (SVD).

**Датасет:** `Goodbooks-10k` (оценки книг пользователями).

**Что было сделано:**
*   Реализовано **SVD (Singular Value Decomposition)** для предсказания оценок.
*   Сформирована матрица «пользователь-книга», данные центрированы по средним оценкам.
*   Рассчитаны метрики качества: **RMSE**, **Precision@k**, **Recall@k**, **Coverage**, **Novelty**, **Diversity**, **Serendipity**.
*   Проанализирована проблема «холодного старта» и разреженность матрицы.

### ✅ Результаты
*   **Точность предсказания:** Модель успешно предсказывает рейтинги, ошибка **RMSE ≈ 0.84**.
*   **Качество рекомендаций:** Сформированы персонализированные TOP-10 рекомендаций для каждого пользователя с высоким показателем Coverage.
*   **Анализ данных:** Выявлена высокая разреженность исходной матрицы (до 98%), что обосновывает применение SVD для снижения размерности и выявления скрытых факторов.

## Практика 3. Обработка естественного языка
**Цель:** Полный цикл NLP-анализа текстов.

**Датасет:** `news.csv` (150 новостей: экономика, спорт, наука).

**Что было сделано:**
*   **Предобработка:** Токенизация, очистка от HTML, удаление стоп-слов (с сохранением «не» и «ни»), лемматизация с помощью `pymorphy3`.
*   **Частотный анализ:** Построен Топ-20 слов и визуализирована столбчатая диаграмма.
*   **Сентимент-анализ:** Определена тональность (позитив, негатив, нейтрально) словарным методом.
*   **NER:** Извлечение именованных сущностей (имена, организации, локации) с помощью библиотеки `Natasha`.
*   **Тематическая классификация:** Векторизация **TF-IDF** + **Logistic Regression**.

### ✅ Результаты
*   **Точность классификации:** Модель тематической классификации (TF-IDF + Logistic Regression) достигла **Accuracy = 89%**.
*   **Извлечение сущностей (NER):** Успешно извлечены имена персон, локации и названия организаций из новостного корпуса.
*   **Анализ тональности:** Проведено распределение текстов по эмоциональной окраске, выявлены ключевые слова для каждого класса.

## Практика 4. Анализ временных рядов
**Цель:** Выявление скрытой структуры временного ряда (на данных температуры в Мурманске).

**Что было сделано:**
*   **Теория пропорций:** Ряд разделен на быстрые (шум, локальные колебания) и медленные (тренд) движения с помощью скользящего среднего.
*   **Обобщенная сдвиговая функция:** Найдены «почти-периоды» (локальные минимумы автокорреляции на сдвигах 182 и 365 дней).
*   **Анаморфозы:** Проверены модели роста.

### ✅ Результаты
*   **Выявление циклов:** Найдены устойчивые «почти-периоды» на сдвигах **182 и 365 дней**, что подтверждает наличие полугодовой и годовой сезонности в данных.
*   **Модель интенсивного роста:** Весенний прогрев хорошо описывается логарифмической анаморфозой — **\( R^2 \approx 0.8 \)**.
*   **Модель ограниченного роста:** Летнее плато описывается логистической анаморфозой — **\( R^2 \approx 0.6 \)**.

## Практика 5. Кластеризация данных
**Цель:** Кластеризация стран без учителя на основе макроэкономических показателей.

**Датасет:** `World Bank` (6 признаков: ВВП, продолжительность жизни, интернет, урбанизация и др.).

**Что было сделано:**
*   Проведена стандартизация данных (`StandardScaler`) и снижение размерности (`PCA`).
*   Реализованы **3 классических метода**: K-Means, Иерархическая кластеризация (Ward), DBSCAN.
*   **Ноу-хау:** Созданы **безразмерные комплексы** (ВВП на год жизни, доля интернета к урбанизации, демографический баланс).

### ✅ Результаты
*   **Сравнение алгоритмов:** 
    *   **K-Means (k=3)** показал лучший результат: `Silhouette = 0.327`, `Davies-Bouldin = 1.099`.
    *   **Иерархическая кластеризация (Ward)** дала `Silhouette = 0.275`.
    *   **DBSCAN** не справился с задачей из-за слишком равномерной плотности данных.
*   **Интерпретация:** Кластеризация по стандартным признакам разделила страны на «развитые», «развивающиеся» и «бедные».
*   **Ноу-хау:** Кластеризация по созданным **безразмерным комплексам** дала более осмысленное с экономической точки зрения разделение стран, учитывающее эффективность использования ресурсов и демографические тренды.
